# hemu-ski 板类资产 Workshop

为游戏 **hemu-ski** 制作雪板资产的工坊仓库。用代码（img2threejs 式纯代码工厂函数）生成模型，零贴图、全纯色、区分靠抽象几何图案，与游戏的 toon 画风一致。

**在线审查页（GitHub Pages）**：打开首页即可使用全部功能——

1. 顶部选择 **单板 / 双板**；
2. **单独审查 360°**：旋转/缩放看板子本体；
3. **穿戴视图**：板子穿在游戏人物脚上的样子——测试人物按用户要求直接用 hemu-ski 的女性角色原模型（`assets/female-rider.glb`，65 骨 Mixamo，按游戏规格缩放至 1.80 m，双骨 IK 站上固定器，与游戏 rider.js 同一解法）；
4. **原地滑行**：人物在原地压刃滑行（IK 姿态逐帧重解 + 整板滚转 + 地面速度线）；
5. **款式面板**：板面/板底/图案/副色/固定器点缀五色 + 六种几何图案（纯色/纵条纹/斜纹/箭头纹/头尾分色/格纹），所有视图实时同步。

另有固定器单独视图：可开「靴子占位」验配合尺寸，单板固定器的踝带/趾带可单独隐藏或整条拆开。迭代过程见 [VERSIONS.md](VERSIONS.md)（自核查截图迭代 20 版）。

`src/` 是 TypeScript 源码（事实源），`lib/` 是 esbuild 打好的 JS（审查页直接引用，改源码后跑 `bash build.sh` 重新生成）。

审查页架构（v21 起 React 化，便于模块化维护）：

- `src/app/` — React 界面层：`types.ts`（UI 状态与规格文案）、`App.tsx`（状态管理）、`components/Toolbar.tsx`（单板/双板与视图切换）、`components/ControlPanel.tsx`（颜色/图案/开关面板）。
- `src/scene/SceneManager.ts` — three.js 场景层：渲染、装配、滑行动画、相机帧位，完全不碰 DOM；React 把状态推给它，结构性变化（装备/视图/配色）才重建场景，绑带/靴子/旋转等轻变化原地应用。
- `src/create*.ts` — 资产工厂（见下表），与页面无关，游戏可直接引用。

## 一切尺寸从游戏人物量出来（src/riderSpec.ts）

- 两名角色按躯干等大（Hips→Head 0.591 m）；含帽/耳总高约 1.80（女）/ 1.87（男）。
- 游戏雪靴外尺寸 0.17 宽 × 0.33 长（rider.js 的靴体），单板站距约 0.52 m。
- 双板鞋底长 0.34（固定器中心两侧各 0.17，rider-skis.js），鞋底站高 0.035，站距 ±0.125。

## 板长与身高的关系（2026-11-03 调研结论）

- **单板**：通用法则「下巴到鼻尖」，数值约 **身高 × 0.88**（170 cm → 150，180 cm → 158）；粉雪/野雪板向上取到鼻尖以上。板长按游戏既定规则「身高 − 10 cm」定锚：用户 2026-11-03 选定女主锚点（工坊测试角色就是她），1.80 − 0.10 → **1700 mm**。（注：×0.88 法则会给出约 1580 mm，此前 1600 mm 即由此而来，现已被身高−10 规则取代。）
- **双板**（全山）：REI/evo 偏移法——初级 身高 −12.5、中级 −2.5、高级 +5 cm；对照表 175 cm 中级为 165–170、178 cm 为 175。游戏人物取 **1700 mm**。（游戏内现占位双板只有 1400 mm，远低于对照表，本工坊双板将取代它。）

来源：snowboardsizecharts.com 尺码表、bodycalculator / Montec 双板尺码表（REI、evo 口径）。

## 固定器结构（只保留必要结构）

- **单板固定器**（参照 2025 现行双绑带款，如 Salomon District 的部件构成）：安装圆盘、底盘+侧栏、鞋床+趾坡、脚跟杯、背板（前倾约 10°，带前倾调节块与顶垫）、踝带、趾帽带、两侧棘轮+梯带。
  **踝带与趾带是独立命名的分组（`strap-ankle` / `strap-toe`），可单独隐藏、拆开、换色**——审查页右侧有开关实证。
- **双板固定器**（参照 Marker Griffon 类现行高山固定器）：安装导轨、前跟（双翼 + AFD 防摩擦滑片 + 顶帽）、后跟（Pivot 式长拉杆 + 后跟颚）、刹车臂（宽 145 适配板腰 105）。不做 DIN 刻度窗与螺丝细节。

## 审查页用法

- 顶部按钮切换 6 个视图：单板 / 双板 / 单板固定器 / 双板固定器 / 装配·单板全套 / 装配·双板全套。
- 拖动旋转、滚轮缩放；右侧面板：自动旋转、靴子占位、绑带开关与拆开、当前资产规格与面数。
- URL 参数（方便截图与直达）：`?asset=binding&boot=1&detach=1&spin=0`。

## 接入游戏时

把 `lib/*.js`（或 `src/*.ts`）拷进 hemu-ski，工厂函数只依赖 three。单板固定器在板上对准孔位包中心（t=0.42 / 0.74，站距 512），双板固定器对准板腰中心；靴子占位不要带进游戏。
